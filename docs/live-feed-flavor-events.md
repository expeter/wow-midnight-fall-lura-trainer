## Later design questions

- How rare should flavor events be relative to genuine activity?
- Should they be labeled `AMBIENT`, `BREAKING NEWS`, or another unmistakably
  fictional category?
- Should randomness happen server-side, client-side, or only after a successful
  activity fetch?
- How should repeated lines be suppressed across tabs and sessions?
- Should flavor events obey the existing live-notification HUD toggle, or have
  a separate toggle?
- Should flavor text appear in the persistent feed, transient messages, or both?
- Which lines need alternate wording for accessibility or localization?
